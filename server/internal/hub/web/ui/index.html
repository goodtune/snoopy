    Desktops running snoopy appear here by themselves when the hub can see them:

    • On each desktop, expose snoopy on the LAN with SNOOPY_ADDR=0.0.0.0 in /etc/snoopy/snoopy.conf and restart it; it then advertises itself over mDNS (Avahi) as _snoopy._tcp.
    • The hub needs avahi-daemon on the same network segment to hear those announcements.
    • Where mDNS does not reach, list desktops in SNOOPY_HUB_STATIC in /etc/snoopy/hub.conf, for example alice=alice-pc.example.net:8900.
